Learning Objectives

Grade 9 English Competencies — Exploring Fauna of Indonesia

By the end of this lesson, I can:

  • Identify key facts and specific information about Indonesian fauna.
  • Describe physical characteristics using descriptive adjectives (e.g., long nose, reddish fur, strong wings).
  • Explain animal habitats, diets, and natural behaviors.
  • Use the Simple Present Tense and verbs has / have correctly.
  • Analyze the Generic Structure of a descriptive text (Identification & Description).
  • Construct structured descriptive paragraphs using guided prompts.
  • Practice spoken descriptions using English speech recognition templates.
  • Demonstrate conservation awareness regarding endangered Indonesian wildlife.

Proboscis Monkey (Bekantan)

Subtopic A — Borneo's Unique Primate

🐒
Status: Endangered (IUCN)

Common Name: Proboscis Monkey

Indonesian Name: Bekantan

Scientific Name: Nasalis larvatus

Habitat: Mangrove forests, coastal wetlands, lowland forests in Borneo.

Diet: Leaves, mangrove shoots, unripened fruits, seeds.

Key Characteristics

1. Large Nose

Male Bekantans have prominent, long noses used to attract females and amplify warning calls.

2. Reddish-Brown Fur

Their coat is soft reddish-brown on the back and gray/cream on the abdomen.

3. Expert Swimmers

Bekantans have webbed feet and hands. They are renowned for swimming across rivers and diving under water.

Indonesian Birds

Subtopic C — Endemic Avian Species

🕊️

Bali Myna (Jalak Bali)

Leucopsar rothschildi

Habitat: Dry forest in Bali, Indonesia.

Appearance: Pure white feathers with blue skin patch around eyes and black wing tips.

Conservation: Critically Endangered.

🦜

Bird-of-Paradise (Cenderawasih)

Paradisaeidae family

Habitat: Tropical rainforests in Papua, Indonesia.

Appearance: Vibrant yellow, green, and red feathers; elaborate courtship dance.

Conservation: Protected under Indonesian law.

🦅

Rhinoceros Hornbill (Rangkong)

Buceros rhinoceros

Habitat: Rainforest canopy in Sumatra, Borneo, Java.

Appearance: Prominent golden-orange casque on top of a large downward beak.

Conservation: Vulnerable / Protected.

🦅

Javan Hawk-Eagle (Elang Jawa)

Nisaetus bartelsi

Habitat: Humid rainforests in Java, Indonesia.

Appearance: Distinctive head crest feather; national symbol inspiration (Garuda).

Conservation: Endangered.

Simple Present Tense, Has/Have, and Descriptive Adjectives

1. Simple Present Tense (Habits & Facts)

We use the Simple Present Tense to describe facts, habits, and physical features of animals.

Plural Subject (They/We/Plural)

Subject + Verb 1

Singular Subject (He/She/It/Singular)

Subject + Verb1 + s/es

Grammar Practice: Choose the Correct Verb Form

2. An orangutan ________ (has/have) long arms for swinging on branches.

3. Jalak Bali ________ (be) a rare bird with white feathers.

Google Apps Script Code.gs Guide

Copy the code below into Google Apps Script connected to your Google Sheet to automatically log student test scores and progress. 

function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    
    // Auto Create Headers if empty
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(["Timestamp", "Student Name", "Class", "School", "Score", "Total Questions", "Percentage", "XP", "Completed Activities", "Date"]);
    }
    
    sheet.appendRow([
      new Date(),
      data.studentName,
      data.className,
      data.school || "-",
      data.score,
      data.totalQuestions,
      data.percentage + "%",
      data.xp,
      data.completedActivities.join(", "),
      data.date
    ]);
    
    return ContentService.createTextOutput(JSON.stringify({"result":"success"}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService.createTextOutput(JSON.stringify({"result":"error", "error": err.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

Setup Steps:

  1. Open your Google Sheet → Click Extensions → Apps Script.
  2. Paste the code above into Code.gs.
  3. Click Deploy → New deployment → Select Web App.
  4. Set "Who has access" to Anyone.
  5. Copy the generated Web App URL into the Teacher Configuration settings in this web application.
